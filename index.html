Latest projects

Identity, access, and automation work designed for secure operations.

Identity Automation

BAESL (Bulk AD Entra Sandbox Loader)

A PowerShell utility for rapidly populating test environments with realistic identity data so admins can validate access patterns, role assignments, and security workflows with confidence.

  • Bulk provisioning for sandbox testing
  • Entra / AD identity simulation
  • Faster secure validation cycles
IAM

PIM-IT: Privileged Identity Management Tool

A PowerShell-based utility that uses Microsoft Graph to simplify the process of assigning and managing PIM roles in a more user-friendly, operationally practical way.

  • Microsoft Graph-based role assignment
  • Improved admin experience
  • Stronger privilege governance
Security Review

Shadowman: Entra App Auditor

A targeted PowerShell script to identify user-consented applications, assess app risk, and highlight dormant or over-privileged apps that may warrant review or removal.

  • Consent and app risk analysis
  • Actionable security reporting
  • Governance and compliance support
Diagnostics

Portman: Port Diagnostics Tool

A PowerShell utility that polls connected ports, logs connection drops, and helps technicians pinpoint intermittent hardware or port reliability issues before they become larger outages.

  • Hardware reliability checks
  • Connection drop logging
  • Operational troubleshooting support
